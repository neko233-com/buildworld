# buildworld233

现代化 CI/CD 服务器 - Jenkins 替代方案，支持 TypeScript DSL、插件系统和分布式 Agent。

## 功能特性

- **TypeScript DSL** - 使用 TypeScript/JavaScript 编写构建流水线
- **插件系统** - 基于 goja 运行时的热重载插件
- **Agent 优先架构** - 分布式构建执行
- **Git/SVN 集成** - 支持 GitHub、GitLab、Gitee、Gitea 和 SVN
- **SSH 认证** - 密钥和密码 SSH 认证
- **环境变量** - 全局和项目级变量
- **参数化构建** - 带验证的构建参数
- **开发环境** - 自动配置 JDK、Maven、Node.js、Gradle
- **模板** - 8+ 内置流水线模板
- **现代化 UI** - React 仪表盘，实时更新

## 快速开始

```bash
# 安装
curl -fsSL https://raw.githubusercontent.com/neko233-com/buildworld233/main/scripts/install.sh | bash

# 启动服务器
buildworld233 start

# 打开浏览器
open http://localhost:6050
```

默认登录: `root` / `root`

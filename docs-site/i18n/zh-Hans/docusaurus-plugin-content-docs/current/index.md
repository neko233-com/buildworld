# buildworld233

现代化 CI/CD 服务器 - Jenkins 替代方案，支持 YAML/JSON 流水线、插件系统和分布式 Agent。

## 功能特性

- **YAML/JSON 流水线** - 支持 GitHub Actions 风格的 YAML 和 JSON 流水线定义
- **插件系统** - 基于 goja JS 运行时的热重载插件
- **Agent 优先架构** - 分布式构建执行，支持 Agent 池和需求匹配
- **VCS 集成** - Git、SVN、Mercurial 支持，带 VCS Roots
- **SSH 认证** - 密钥和密码 SSH 认证，带凭证管理
- **环境变量** - 全局和项目级变量
- **参数化构建** - 带验证的构建参数
- **开发环境** - 自动配置 JDK、Maven、Node.js、Gradle
- **构建模板** - 可复用的构建模板，支持项目级覆盖
- **构建触发器** - 定时（cron）、VCS 轮询和完成触发器
- **产物管理** - 安全的产物存储，带 SHA256 验证
- **通知系统** - 邮件、飞书和 HTTP Webhook 通知
- **国际化** - 中英文支持，自动检测浏览器语言
- **现代化 UI** - React 仪表盘，实时更新

## 快速开始

```bash
# 安装
curl -fsSL https://raw.githubusercontent.com/neko233-com/buildworld233/main/scripts/install.sh | bash

# 启动服务器
buildworld233 start

# 打开浏览器
open http://localhost:6050
```

默认登录: `root` / `root`
